# Additional and adapted code in w5p

Prepared for the quarterly enhancement review, October 30, 2026. Companion to the [methodological departures and justifications](MOLINA_ROMERO_DEVIATIONS_w5p.md).

## Scope and attribution

This inventory explains the Workbench implementation surrounding the framework in Molina and Romero (2025), *Comparable Small Area Estimates over Time*. It is a functional inventory, not a verified file-by-file difference from the authors' original code: that original code bundle is not available in this checkout. “Additional” therefore means Workbench support, adaptation or extension beyond the manuscript's mathematical specification, not a claim of wholly original authorship. Several files combine existing methods, package calls and project-specific logic. In particular, the robust MFH2 wrapper adapts `msae`; transformed UFH uses `emdi`. These packages and their methods must retain their own attribution.

The inventory covers the principal statistical files and groups supporting application code by purpose. It does not list every launcher, asset, test or build utility. These additions accumulated through w5p; they were not necessarily introduced in w5p itself. Source links refer to the current checkout, so a release review should also record its Git revision.

## Estimation, numerical safeguards and uncertainty

| Code | What it does | Why it is needed; relationship to the manuscript |
|---|---|---|
| [scripts/eblupMFH2_robust.R](../../scripts/eblupMFH2_robust.R) | Calls the original compatibility-patched `msae::eblupMFH2`, checks its REML endpoint, and when necessary attempts bounded, multiple-start optimization of marginal variance and correlation. Reconstructs the expected model object and records refit status. | A package convergence flag can accept an unsuitable likelihood endpoint. This is a numerical safeguard for the same stationary MFH2 model, not a new covariance model. A valid zero-variance boundary alone does not require refitting. Failed or inferior refits are flagged rather than silently substituted. “Robust” here means optimization safeguards, not robustness to outliers or model misspecification. |
| [R/mfh_convergence_check.R](../../R/mfh_convergence_check.R) | Independently checks MFH fitting endpoints, including likelihood derivatives, curvature and feasible boundary behavior. | Distinguishes numerical validity from a package's stopping flag and supports decisions on refits and usable bootstrap draws. A numerically valid boundary fit can still have poor interval coverage. |
| [R/msae_compat.R](../../R/msae_compat.R) | Patches the specific vector-valued `diff >= PRECISION` expression used with scalar `&&` in package convergence checks; preserves missing call arguments. | Keeps the package routines executable under newer R versions without broadly rewriting their estimation code. This is a compatibility repair, not a methodological departure. |
| [R/mfh_model_selection.R](../../R/mfh_model_selection.R) | Implements the MFH3 variance-contrast decision and records fallback reasons for selecting MFH2. | Makes the manuscript's selection sequence operational when MFH3 is requested and prevents unavailable tests or failed fits being treated as positive evidence for MFH3. Starting with MFH2 by default is a separate pragmatic departure, motivated by recorded convergence difficulties. |
| [R/mfh_bootstrap_helpers.R](../../R/mfh_bootstrap_helpers.R) | Provides shared MFH1/2/3 covariance construction, simulation, sampling-covariance preparation, refitting and prediction. Calculates annual MSEs and cross-period MCPE from the same accepted prediction-error vectors, with failure, boundary and Monte Carlo diagnostics. Also supports conditional-lognormal prediction and final-scale postprocessing. | Supplies the joint bootstrap implementation needed to operationalize change uncertainty; the manuscript identifies bootstrap development as open. Shared draws preserve `MSE(change) = MSE1 + MSE2 - 2*MCPE`. Model/variable selection and estimated sampling inputs remain fixed, so this is conditional uncertainty. |
| [scripts/pbmcpeMFH1_with_existing_eblup.R](../../scripts/pbmcpeMFH1_with_existing_eblup.R), [MFH2 wrapper](../../scripts/pbmcpeMFH2_with_existing_eblup.R), [MFH3 wrapper](../../scripts/pbmcpeMFH3_with_existing_eblup.R) | Thin model-specific entry points into the shared bootstrap engine; reuse the existing fitted point estimates while estimating uncertainty. | Prevents comparison/report steps from obtaining a different original fit merely to calculate uncertainty. These are three interfaces to one engine, not three independently developed bootstrap methods. |
| [scripts/pbmcpe_with_existing_dispatch.R](../../scripts/pbmcpe_with_existing_dispatch.R) | Selects the matching bootstrap wrapper and exposes a common result structure. | Keeps downstream comparison code consistent across MFH variants. This is integration support. |
| [R/variance_policy.R](../../R/variance_policy.R) | Resolves direct, selective and full smoothing settings and matching covariance defaults. Under `sm_out`, replaces missing/nonfinite variances or values strictly below 0.001. | Ensures the UI, saved settings and estimators apply the same policy. The cutoff is an application choice, not prescribed by Molina and Romero; it is scale-dependent and does not replace large variances. |
| [scripts/ufh_functions.R](../../scripts/ufh_functions.R) | Collects FGT calculations, GVF smoothing, selection and UFH fitting helpers, transformation/back-transformation, raw Direct-variance restoration, ratio benchmarking and UFH bootstrap support. | Connects household-survey indicators to area models and supports the extended reporting scales. The GVF retransformation uses a lognormal conditional-mean correction; transformed UFH draws on `emdi`, including its distinct log correction. This mixed-purpose file should not be described as an entirely new estimator or wholly original code. |
| [scripts/bench_regional_mfh.R](../../scripts/bench_regional_mfh.R) | Applies population-weighted ratio benchmarking to national/group targets and integrates the final-scale adjustment with uncertainty calculations. | Added following the EMDI team's recommendation to reconcile small-area estimates with chosen aggregates. Benchmarking is an extension beyond the supplied manuscript's discussion; reconciliation does not establish improved accuracy. Uploaded targets are treated as fixed, whereas survey-derived targets are recomputed within draws. |

## Survey preparation and analysis orchestration

| Code | What it does | Why it is needed; relationship to the manuscript |
|---|---|---|
| [scripts/01_ufh.R](../../scripts/01_ufh.R) | Runs survey Direct estimation, variance preparation, annual UFH fitting, diagnostics and exports. | Converts the research model into a repeatable survey-to-output workflow. Separate annual UFH change calculations assume period independence; separate fitting does not establish that assumption. |

| [R/input_readers.R](../../R/input_readers.R), [R/input_paths.R](../../R/input_paths.R), [R/input_preflight.R](../../R/input_preflight.R), [R/validation_checks.R](../../R/validation_checks.R) | Resolve files, read and validate inputs, and check readiness before estimation. | Prevents mismatched years, duplicate keys, invalid settings and incomplete required MFH panels from silently entering estimation. ## Suggested explanation at the review meeting

The additional code makes the Molina–Romero framework executable, more defensible numerically and usable for country reporting. Some modules implement the framework, some repair compatibility or numerical problems, and others extend the indicators, uncertainty calculation or reporting. In particular, `eblupMFH2_robust.R` improves how the existing MFH2 likelihood is optimized and checked; it does not change MFH2 into a different statistical model and does not cure boundary-related undercoverage.

The core covariance specifications and change-MSE identity are retained. The substantive choices needing review are the MFH2 starting model, two-year restriction, variance/covariance policy, transformed predictions, conditional bootstrap, benchmarking and interpretation of multiple comparisons. See the [deviations register](MOLINA_ROMERO_DEVIATIONS_w5p.md) for their justifications and the [validation receipt](../validation/W5P_VALIDATION_RECEIPT.md) for the scope of existing checks. This documentation inventory supplies no new coverage evidence.
