Revision status against the merged issue register

Baseline: EU SAE application package v5.1.0. Current local review candidate: 5.2.0-rc.6-wizard.5.16 (w5p), revising w5o (5.15) and the QER candidate w5n (5.14).

w5p repairs matrix-year/key validation, pre-cleanup readiness, raw Direct uncertainty, logged benchmark factors and standalone MFH figure qualifications. It retires the dormant bootstrap implementation and synchronizes methodology guidance. See the deviations note and fresh validation receipt. The historical issue register and coverage limitations below remain in force.

The older issue register is retained below. The current technical disposition and evidence are in QER review note and methodology alignment; open institutional approvals are not software defects that a local revision can close.

The owner's w5p follow-up sets sm_all/rho_sm_all as applicable defaults while preserving explicit saved policies and arcsine UFH's distinct variance treatment. The optional sm_out policy and its validation limitation remain. T=2 is a deliberate publication-policy choice: successive windows and freezing each year after its second appearance limit routine revisions; the app does not manage the NSO's publication register.

Implemented means the candidate contains a code or documentation change for the finding; it is not a production-method approval. Partial identifies work done but an unresolved decision or validation. Open means no substantive closure is claimed.
