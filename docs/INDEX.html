Start an analysis

Open this guide from the extracted package. It works offline and does not start R. Use the guided application for a new analysis.

1. Extract and prepare

Extract the whole application ZIP. Install R 4.2 or later using a version approved by your organization. Keep the package folders together. The launcher installs missing R packages on first use, so allow an internet connection and time for setup. It reuses Pandoc or downloads a verified copy for HTML/Word reporting.

2. Open the guided application

Open Start_Here and use the launcher for your computer. Keep its terminal window open while working. Choose New model run, or Load saved configuration to continue with saved settings.

3. Run the seven steps

Choose your input files, check variable mappings and model settings, then run Check data readiness in Step 6. In Step 7, select Run model. AI report writing is optional and requires separate consent.

4. Review and retain the run

Use Open the report and Open the run folder when the run finishes. Review diagnostics, uncertainty and any AI advice before using the findings. Save a separate copy of the Word report before editing it.

Find your results

outputs/ is reused by later runs. app_runs/ holds dated run folders. app_runs/_last_setup_files contains saved-setup support files and is not a run archive. A newly extracted package has no generated reports yet.

What you needLocation and use
Current reportoutputs/final_report.html
Open in a browser after a completed run. Keep outputs/data beside it for linked workbooks.
Editable reportoutputs/final_report.docx
Open in Word. Save a separate working copy before editing.
Consolidated resultsoutputs/data/EU_SAE_results.xlsx
Excel estimates, changes and diagnostics when the relevant steps complete.
Figures and diagnostic tablesoutputs/figures/ and outputs/tables/
Maps, plots and detailed diagnostics from the current run.
A previous runapp_runs/<run folder>/outputs/
Archived results; the parent run folder contains saved configuration and logs. Retain original inputs separately.

Use the application’s Open the report, Open the output folder and Open the run folder controls. The guide lists locations rather than linking to reports that do not exist before your first run.

If something goes wrong

For startup problems, read Start_Here/README.md and startup_setup.log. If analysis completes without a report, inspect the run log for Pandoc or Word-conversion messages. The Guides and notes menu links to the same documentation catalogue.
