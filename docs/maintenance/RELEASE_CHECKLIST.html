Release checklist

A release manager must record evidence for every item before changing the candidate label to a production version.

The w5p local review candidate adds input/reporting repairs and synchronized documentation. Its fresh receipt and deviations note distinguish execution checks from unresolved statistical validation. A local verification ZIP is not the owner's committed release build.

For the w5n pre-release (QER candidate), completed Windows checks and their scope are recorded in the validation receipt. The w5o pre-release changes the interface and adds the survey-unit and benchmark-group checks; its tests and the Spain example check (household-level data, estimates identical to w5n) are listed in the w5o entry of the changelog. The production release gates below remain separate from that candidate review.
